# Country flag assets

The PNG files in this folder were rendered at 96 px wide from the SVG sources in
the `hampusborgos/country-flags` project:

https://github.com/hampusborgos/country-flags

The source project identifies the flag artwork as public domain. Country and
territory names are copied from its `countries.json` file. The source revision
used for this import was `c09927e63705529bbf59ca6684cd9b23225dddad`.
